# Verified anchored cube duplication escape

Every nonempty subset S avoiding a zero anchor has a member whose
duplication leaves the entire anchored cube, at odd cyclic modulus.
The first theorem assumes injective doubling explicitly; the odd-modulus
corollary supplies it. The argument selects a largest return layer and
uses shortest-representation rigidity to force an impossible zero
coordinate if all duplications return.

Both results hold in arbitrary dimension and at every subset size.
They prove an escape for each subset, without asserting distinct escapes
for different subsets or linear independence of the proposed matrix.
The aggregate central outside-cube count and G1/G2/G3/CR1 remain open.

external theorem interface types, two existing definition values and
one exact original doubling-injectivity helper type. No new definition
bundle is introduced. Exact compiler spans retain the original proof
bodies. Metadata and live preflight pass; private publication is pending.
